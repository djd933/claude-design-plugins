# /image-to-code

The user should attach a design reference (screenshot, mockup, or photo of a UI).

1. Analyze the image per the image-to-code skill: layout, palette, typography, components, spacing, signature details.
2. Plan the structure in a few lines before coding.
3. Build it in the project's framework (or clean HTML/CSS), responsive, with CSS variables for the palette.
4. Summarize what you matched and any inferences you made for unclear parts.
