# image-to-code

Turns any design reference image into usable frontend code while preserving the important details.

## What it does

Attach a screenshot or mockup, and it analyzes layout, palette, typography, components, and signature details, then builds it as clean responsive code.

## Install

```
/plugin install image-to-code@design-plugins
```

## Usage

Attach your reference image and run `/image-to-code`. It plans the structure first, then builds.
