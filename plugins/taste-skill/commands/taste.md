# /taste

Do a design-taste pass on the current project or the files the user points to.

1. Review the main pages/components for generic AI-template signs (default fonts, harsh gradients, flat spacing).
2. Apply the taste skill principles: distinctive typography, 8pt spacing rhythm, restrained color, refined details.
3. Make the edits, then summarize what changed and why in 3-5 bullets.

If no frontend files exist yet, ask what they're building and propose a taste direction first.
