# taste-skill

Applies premium design taste references so Claude Code websites don't look like generic AI templates.

## What it does

Auto-activates on frontend work and applies:
- Distinctive typography pairings
- 8pt spacing rhythm with generous whitespace
- Restrained color palettes
- Refined details (borders, shadows, radii, motion)

## Install

```
/plugin install taste-skill@design-plugins
```

## Usage

Just build normally - the skill activates automatically on frontend tasks. Or run `/taste` for an explicit taste pass.
