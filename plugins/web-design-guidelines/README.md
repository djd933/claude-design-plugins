# web-design-guidelines

Audits your UI against modern web design principles and catches weak areas before you ship.

## What it does

- Full checklist: hierarchy, typography, color/contrast, layout, components, polish
- Specific, file-and-line findings ordered by user impact
- Optional fix pass

## Install

```
/plugin install web-design-guidelines@design-plugins
```

## Usage

Run `/audit` on any frontend project. Add "and fix" if you want it to apply the fixes too.
