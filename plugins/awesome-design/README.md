# awesome-design

Complete design system for Claude Code: colors, typography, spacing, buttons, cards, inputs, badges, and page patterns.

## What it does

Provides copy-paste tokens (CSS variables) and component specs so every page you generate looks consistent and professional.

## Install

```
/plugin install awesome-design@design-plugins
```

## Usage

Run `/design-system` when starting a new page, or just build - the skill auto-activates on new frontend work and keeps styling consistent.
