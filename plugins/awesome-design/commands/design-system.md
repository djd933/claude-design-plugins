# /design-system

Build with the Awesome design system.

1. If starting fresh, set up the color/typography/spacing tokens from the skill first.
2. Build the requested page/component using the component patterns (button, card, input, badge, hero, section header, feature grid).
3. Adapt the primary hue to the project's brand if one exists; otherwise use the default.

Report which tokens and patterns you used.
